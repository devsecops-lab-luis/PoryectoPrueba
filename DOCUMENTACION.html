1. Introducción

ProyectoPrueba es una plataforma empresarial moderna diseñada para la gestión eficiente de tareas por usuario. El proyecto se encuentra en fase de scaffold inicial, con la arquitectura base completa y lista para el desarrollo de módulos específicos.

🎯 Objetivo Principal

Proporcionar una solución integral para que los usuarios puedan crear, organizar, asignar y monitorear tareas de forma colaborativa, con autenticación segura y auditoría completa de operaciones.

✨ Características Principales

  • Gestión de Tareas: Crear, actualizar, eliminar y completar tareas
  • Autenticación JWT: Sistema seguro con tokens de acceso y refresco
  • Gestión de Usuarios: Roles, permisos y control de acceso
  • Auditoría: Registro completo de todas las operaciones
  • Notificaciones: Sistema de alertas para eventos importantes
  • Documentación Swagger: API completamente documentada
  • Containerización: Docker y Docker Compose para despliegue

3. Arquitectura del Proyecto

El proyecto sigue una arquitectura de monorepo con separación clara entre backend y frontend, facilita el desarrollo independiente y simultáneo de ambos componentes.

Flujo de Autenticación

  1. Login: Usuario envía credenciales (email + password)
  2. Validación: Backend valida y compara password con bcrypt
  3. Token Generation: Se genera JWT con access_token y refresh_token
  4. Almacenamiento: Cliente guarda tokens (localStorage/sessionStorage)
  5. Requests Autenticados: Todas las requests incluyen el access_token en headers
  6. Refresh: Al expirar, se usa refresh_token para obtener nuevo access_token

5. Configuración e Instalación

📋 Requisitos Previos

  • Docker & Docker Compose: Para ejecución en contenedores (recomendado)
  • Node.js 18+: Si ejecutas localmente
  • npm o yarn: Gestor de paquetes
  • PostgreSQL 15+: Si no usas Docker
  • Git: Para control de versiones

🚀 Instalación Rápida (Recomendado - Docker Compose)

# 1. Clonar el repositorio git clone https://github.com/LuisssGit/PoryectoPrueba.git cd PoryectoPrueba # 2. Revisar variables de entorno cat .env.example # 3. Crear archivo .env (opcional, Docker usa defaults) cp .env.example .env # 4. Construir e iniciar servicios docker compose up --build # El proyecto estará disponible en: # - Frontend: http://localhost:3000 # - Backend: http://localhost:3001 # - Swagger: http://localhost:3001/api/docs # - Base de datos: localhost:5432

⚙️ Instalación Local

# Backend cd backend npm install npm run prisma:generate npm run prisma:migrate npm run start:dev # En otra terminal - Frontend cd frontend npm install npm run dev

🔐 Variables de Entorno Importantes

# Backend DATABASE_URL=postgresql://user:password@localhost:5432/proyectoprueba JWT_SECRET=tu_secret_key_muy_seguro JWT_EXPIRATION=3600 JWT_REFRESH_EXPIRATION=604800 NODE_ENV=development PORT=3001 # Frontend VITE_API_URL=http://localhost:3001 VITE_API_PREFIX=/api
⚠️ Importante: Nunca comitees el archivo .env con credenciales reales. Usa .env.example para proporcionar plantillas a otros desarrolladores.

6. Módulos Principales

🔐 Auth Module

Maneja la autenticación y autorización del sistema.

Endpoints principales:
  • POST /auth/register - Registrar nuevo usuario
  • POST /auth/login - Iniciar sesión
  • POST /auth/refresh - Refrescar token JWT
  • POST /auth/logout - Cerrar sesión
  • GET /auth/profile - Obtener perfil actual

👥 Users Module

Gestión de usuarios, roles y permisos.

Endpoints principales:
  • GET /users - Listar usuarios
  • GET /users/:id - Obtener usuario específico
  • PUT /users/:id - Actualizar usuario
  • DELETE /users/:id - Eliminar usuario
  • GET /users/:id/tasks - Tareas del usuario

✅ Tasks Module

Sistema completo de gestión de tareas.

Endpoints principales:
  • GET /tasks - Listar tareas del usuario
  • POST /tasks - Crear nueva tarea
  • GET /tasks/:id - Obtener detalle de tarea
  • PUT /tasks/:id - Actualizar tarea
  • DELETE /tasks/:id - Eliminar tarea
  • PATCH /tasks/:id/status - Cambiar estado
  • GET /tasks/filter - Filtrar por criterios

📝 Audit Module

Registro y auditoría de todas las operaciones.

Funcionalidades:
  • Registro automático de creación/actualización/eliminación
  • Historial de cambios
  • Trazabilidad de usuario y timestamp
  • Búsqueda y filtrado de logs
  • GET /audit/logs - Obtener logs

🔔 Notifications Module

Sistema de notificaciones para eventos importantes.

Tipos de notificaciones:
  • Tareas asignadas
  • Recordatorios de vencimiento
  • Cambios de estado
  • Mensajes de usuario
  • GET /notifications - Listar notificaciones
  • PATCH /notifications/:id/read - Marcar como leído
